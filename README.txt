CALLBACK REMINDER - GitHub Pages
1. Upload all files/folders inside this ZIP to the root of your GitHub repository.
2. Enable Settings > Pages > Deploy from branch > main > / (root).
3. Open the published GitHub Pages URL on Android.
4. Use Chrome menu > Add to Home screen / Install app.
5. On first launch create a 4-digit PIN.

Note: callbacks are stored locally in the browser/device. Browser notifications require notification permission and Android/browser support. For the most reliable reminders, keep notifications enabled and install the PWA.
